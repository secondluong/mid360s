# 板载局域网查看页

地图和轨迹在开发板上累积。同一 WiFi 下的浏览器只打开页面查看。

```
http://<T6 的 WiFi IP>:8080
```

无雷达时本机预览：

```bash
pip install -r requirements.txt
python server.py --demo
```

然后打开 http://127.0.0.1:8080

页面工具栏（只影响本机显示，不改板上地图）：

- **图层**：点云 / 设备 / 轨迹 / 信息
- **实时 / 持久地图**：实时看最近一帧或 3s/10s/30s；持久看板上累积图
- **仅水平 ±m**：只留设备高度附近的点（墙面高度）
- **剖切 + 楼层**：按自动识别或指定层高分层；「识别楼层」可重算
